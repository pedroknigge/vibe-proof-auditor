# Demo skill (v0.9.7)

Run `python3 scripts/run.py`.

## Antigravity (agy)

The repository installer materializes this fixture as a direct child at:

- `~/.gemini/config/skills/demo-skill`
- `~/.gemini/antigravity-cli/skills/demo-skill`

Invoke it with `/demo-skill` after installation. There is no `~/.agy/skills` path.
